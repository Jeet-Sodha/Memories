# Memories — your life, mapped

Flutter + Supabase. Private, location-based memory app:
**Map → Memory preview → Story viewer**, plus Create, Memories timeline,
Search and Profile. Design follows the Stitch "Midnight" screens.

This zip contains **only the Dart source (`lib/`)**, helper scripts and Docker
files. The `android/` and `ios/` folders are generated by Flutter itself.

---------------------------------------------------------------------
## 0. Put your Supabase values in (required)

Edit `lib/config/supabase_config.dart`:

    static const String url = 'https://xxxx.supabase.co';
    static const String publishableKey = 'sb_publishable_...';

Use the **publishable** key. Never the secret / service-role key.

---------------------------------------------------------------------
## A. Run with Docker (builds an Android APK)

Needs Docker Desktop only. No Flutter install required.

    docker compose build
    docker compose run --rm memories          # builds output/memories.apk
    docker compose run --rm memories analyze  # only checks the code

First build takes ~10-20 min (downloads Gradle/Android libs); later builds are
much faster thanks to cached volumes.

Install the APK on an Android phone:
  * copy `output/memories.apk` to the phone and open it
    (allow "install unknown apps"), or
  * USB debugging on, then `adb install -r output/memories.apk`

Docker limits (physical reality, not a bug):
  * It cannot build/run the **iOS** app (Apple requires macOS + Xcode).
  * It cannot show an emulator window. You test on a real phone.
  * The app uses phone-only features (camera roll, mic, files), so it is
    not a web app.

If you change Dart code or the config, just run `docker compose run --rm
memories` again (no image rebuild needed).

## B. Run normally with Flutter installed (needed for iOS)

    flutter create --org com.example --project-name memories_app --platforms=android,ios memories_app
    cd memories_app
    rm -rf lib test
    cp -r /path/to/this/lib ./lib
    flutter pub add supabase_flutter google_fonts flutter_map:^7.0.2 latlong2 \
      geolocator geocoding image_picker file_picker:^8.1.6 flutter_image_compress \
      path_provider path video_player audioplayers record cached_network_image \
      shared_preferences intl
    python3 /path/to/this/tools/apply_platform_config.py .
    flutter run

iOS extra: in `ios/Podfile` make sure the first line is `platform :ios, '13.0'`,
then `cd ios && pod install`. Test on a real iPhone.

## What's implemented

Auth (sign up / log in / log out / session persistence) · onboarding (once) ·
dark CARTO map with circular photo pins, selected state, clustering + cluster
sheet · memory preview card · full-screen story viewer (photos, videos, voice,
ordered by display_order, tap/hold/auto-advance, favorite) · create memory
(multi-media, reorder, record voice, current/picked location, date, upload
progress, rollback on failure) · memories timeline with filters · search ·
profile (avatar upload, stats, edit name) · loading / empty / error states.

All media buckets stay PRIVATE: the app stores storage *paths* and shows media
through short-lived signed URLs.

## Not included (by design)
Memory trails (optional), social features, tags/songs (not in your DB).
